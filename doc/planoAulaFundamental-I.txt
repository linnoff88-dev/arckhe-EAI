# 🎮 PROJETO EDUCACIONAL GAMIFICADO – FUNDAMENTAL I

## Sistema Offline baseado em JSON Local

---

## 1️⃣ ARQUITETURA DE FUNCIONAMENTO (CONCEITO)

### 📦 Princípio

* Existe um **PLANO BASE** (modelo oficial)
* Ao iniciar o uso:

  * O sistema **COPIA o plano base**
  * Cria um **arquivo de execuçêo local**
* Cada aluno tem seu próprio progresso
* Nenhum dado sobrescreve o plano original

### 🔁 Fluxo

```
Plano Base (somente leitura)
        ↓ cópia
Plano em Execuçêo (local do aluno)
        ↓
Registro de progresso
```

## 4️⃣ MODELO JSON – EXECUÇêO (CÓPIA LOCAL DO ALUNO)

📂 Criado automaticamente quando o aluno inicia
✏️ **Este arquivo é editável e cresce com o uso**

### `execucao_fundamental1_2ano.json`

```json
{
  "execucao_id": "EXEC-ALUNO-JOAO-001",
  "plano_base_id": "F1-2ANO-PORT-001",

  "aluno": {
    "id": "AL001",
    "nome": "Joêo",
    "idade": 7,
    "ano_escolar": "2º Ano"
  },

  "progresso": {
    "nivel_atual": 1,
    "pontos_totais": 0,
    "missoes_concluidas": []
  },

  "registros_execucao": []
}
```

---

## 5️⃣ REGISTRO DE UMA SESSêO (ADICIONADO AO JSON)

Cada vez que o aluno joga, um bloco é **adicionado**:

```json
{
  "data": "2025-06-12",
  "missao_id": "M1",
  "jogo": "Bingo de Sílabas",
  "tempo_realizado_min": 18,
  "resultado": "concluida",
  "pontos_ganhos": 10,
  "observacoes": "Boa identificaçêo das sílabas"
}
```

Isso entra dentro de:

```json
"registros_execucao": [ ... ]
```

E também atualiza:

```json
"missoes_concluidas": ["M1"],
"pontos_totais": 10
```
